A student asks

“I just finished CMPSC 132. Plan my next two semesters for the CS major.”

  1. OrchestratorReads the message with the conversation history, resolves the follow-up, and returns a structured plan: domain transcript, deliverable two-semester plan, allowed tools, success criteria.
  2. ExecutorRetrieves the transcript, major requirements and course data from local RAG stores, then calls the deterministic graduation planner. Web research only for fresh facts, with sources validated.
  3. FinalizerChecks the result against the success criteria, rejects unsupported claims, and writes the answer. Every request can return a full debug trace.

Format: a line starting with "Semester N", course codes like CMPSC 132, and an optional "Total credits: N". Credit loads outside 12–19 are flagged. Honors variants such as MATH 140H count toward the base course.

Built to be trusted, and honest about its gaps.

Grounded

Answers come from retrieval over transcripts, courses, majors and policy documents before any web search.

Deterministic where it counts

Graduation planning is code, not generation, so prerequisite order and credit loads are computed.

Measured

An eval harness reports hallucinated courses, prerequisite violations, duplicates and latency over 15 requests in six majors.

Not production yet

Auth is lightweight and some state is process-local. The full app needs an OpenAI key and runs locally or in Docker.
